# Flappy Bird - Fullscreen Web Game

A simple **Floppy Bird** clone made using **HTML, CSS, and JavaScript**. The game runs in the browser and is fully playable on desktop and mobile screens.


## Features

- Fullscreen canvas with smooth gameplay
- Click or press any key to make the bird flap
- Randomly generated pipes with a gap
- Score tracking
- Game over screen with restart option
- Lightweight and responsive design

## How to Play

1. Open `index.html` in a browser or use [GitHub Pages URL](https://bhuvana908.github.io/flappy-bird-web/).  
2. Press any key or click to make the bird flap.  
3. Avoid hitting the pipes or the ground.  
4. Your score increases for every pipe you successfully pass.  
5. When the game ends, press any key or click to restart.
